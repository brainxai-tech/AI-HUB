# Game Feel Tuning

## Expressive register

`Character / playful`。角色是圆润、有表情的原创怒羽与果冻盗贼；视觉采用高饱和强调色、柔和轮廓和夸张但短促的反馈。

## Effect budget

- 拉弓：角色最多 8% 的呼吸缩放，弹力带实时跟随。
- 发射：6 个短寿命羽毛粒子，一次 90ms 的轻微镜头 kick。
- 红鸟精准：中心线有效命中显示金色“精准 +320”、一次 90ms 轻震和强化伤害；同一结构每发最多奖励一次。
- 蓝鸟分裂：离弦至少 480ms 后，在战场中段或目标邻域触发一次 18 粒青色羽流；三只同形象缩小飞鸟先在触发点关闭重力与碰撞、重合保持 90ms，再从同一点纵向散开；1000ms 兜底，每发最多 3 个活动飞鸟实体。
- 黑鸟爆炸：飞出弹弓右侧 150px 空间安全区后才武装；之后首次碰撞生成 168px 范围环、24 粒橙色碎屑和一次 150ms 震动，每发只触发一次。
- 绿鸟穿透：触发时透明度降至 58%、一次 16 粒绿色羽流和 90ms 轻震；每发只穿过首个建筑障碍，鸟体完整越过出口边界后立即恢复不透明与正常碰撞。
- 火铳拦截：显示常驻短标签区分“火铳就绪 / 锁定 / 开火 / 空膛”；锁定使用一条不遮挡建筑的细红线与小型准星，开火使用 170ms 弹道、12 粒枪口火花和 82ms 轻震。
- 高速飞行：每 80ms 一个残影，屏幕同时最多约 12 个。
- 普通撞击：4–7 个材质色碎屑；只有冲击速度大于阈值才触发。
- 物体摧毁：10–16 个碎屑、70–130ms 震动；关键击破才使用白色闪光。
- 胜利：一轮边缘星芒，不遮挡结算文案。

## Thresholds

- 伤害冲击阈值：相对速度 `> 1.8`。
- 残影速度阈值：速度 `> 8`。
- 强震动阈值：目标被消灭或冲击值 `> 16`。
- 连锁窗口：`2200ms`。
- 黑鸟起爆保险：弹弓锚点右侧 `150px` 的空间边界；武装状态越界后永久锁存。
- 红鸟精准破点：相对速度 `>= 8`，中心线归一化偏差 `<= 0.34`；伤害 `×1.32`，奖励 `320` 分。
- 蓝鸟自动分裂：离弦至少 `480ms`，横坐标达到 `590px` 或距最近目标 `<= 360px`；最迟 `1000ms`。
- 绿鸟相位窗口：按障碍厚度和入射速度计算，限制在 `110–420ms`；截止时若仍重叠，先确保鸟体位于障碍出口之外再恢复正常碰撞。
- 火铳进入战场阈值：飞行至少 `80ms` 且横坐标达到 `180px`；锁定窗口 `320ms`，弹道表现 `170ms`，每枚怒羽最多拦截一次。
- 铁盔破甲反馈保护：`260ms`，期间同一碰撞连锁不能继续扣除目标生命。
- 弹体静止判定：速度 `< 0.48` 持续约 `900ms`，且飞行至少 `1800ms`。

## Readability safeguards

- 所有缩放、闪光、残影均为渲染层效果，不改变 Matter 碰撞体。
- 镜头震动最大强度限制为 `0.006`，不改变相机缩放。
- 轨迹点在拖拽时显示，发射后立即隐藏。
- 粒子放在角色和建筑下方或同层，中央不会出现常驻特效。
- `prefers-reduced-motion` 下，DOM 动效减少；游戏镜头震动可由音效按钮旁的系统偏好自动减弱。
