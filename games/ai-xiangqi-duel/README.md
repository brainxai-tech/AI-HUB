# AI Xiangqi Duel

A HUB-ready web MVP for playing Chinese chess against an AI opponent. The app requires a local Pikafish-compatible Xiangqi engine for moves and hints, so it will not silently use the weaker heuristic engine in normal play.

The app follows the AI HUB tool pattern: the rules layer validates every move, Pikafish chooses moves and hints, and an optional model coach can explain engine facts in Chinese. The coach supports DeepSeek, GPT, Claude, and Gemini through the shared AI Project Hub gateway.

## Commands

- Install: `npm install`
- Dev: `npm run dev`
- Test: `npm test`
- Type check: `npm run check`
- Build: `npm run build`

## Engine And Secret Handling

Local move selection does not require a model API key, but it does require `PIKAFISH_PATH`. Model explanations and game reviews are generated by the project server through AI Project Hub, using `HUB_PROJECT_TOKEN` from `.env.local`; provider API keys stay inside the Hub model configuration and are never exposed to the browser project.

Required deployment environment:

```powershell
$env:HUB_PROJECT_TOKEN = "<same token configured in AI Project Hub>"
$env:HUB_CHAT_COMPLETIONS_URL = "http://127.0.0.1:4194/api/v1/chat/completions"
$env:HUB_MODEL_CONFIG_URL = "http://127.0.0.1:4194/api/model-config"
```

When deploying below a HUB subpath, build with:

```powershell
$env:NEXT_PUBLIC_BASE_PATH = "/xiangqi"
npm run build
```

To use the dedicated Xiangqi engine, download/build Pikafish and point the server at the binary:

```powershell
$env:PIKAFISH_PATH = "C:\path\to\pikafish.exe"
npm run dev
```

If you keep the binary inside this project, still set the path explicitly, for example:

```powershell
$env:PIKAFISH_PATH = ".\engines\pikafish\pikafish.exe"
npm run dev
```

Keep engine binaries outside git unless you make an explicit licensing/package decision. If `PIKAFISH_PATH` is not configured, the move, hint, and post-game analysis APIs return `PIKAFISH_REQUIRED` instead of letting the weak heuristic engine play.
