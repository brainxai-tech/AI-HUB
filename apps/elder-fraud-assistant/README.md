# 先问问 - 老人防骗助手

面向老人和子女的本地防骗 MVP。把可疑短信、电话话术、投资群消息放进去，系统用大白话说明风险，并生成一段可以发给子女确认的消息。

## 当前功能

- 上传截图预览，保留可疑信息上下文。
- 粘贴短信、电话、群消息文字后做本地风险判断。
- 填写自己的 API Key 后，可调用大模型复核风险。
- 支持 GPT / OpenAI、Gemini、DeepSeek、Claude。
- 输出三档结果：先别动、很可疑、基本正常但要确认。
- 标出可疑点：催转账、保密、公检法、投资高收益、远程软件、验证码等。
- 生成“问子女确认”的消息和“子女可直接回复”的话。
- 提供投资群、陌生电话、退款短信三个示例。

当前版本保留本地规则引擎作为兜底，并通过本机 Node 服务代理大模型请求，避免浏览器直接跨域调用模型接口。

## 大模型配置

页面里的默认模型：

- GPT / OpenAI：`gpt-5.2`
- Gemini：`gemini-3.5-flash`
- DeepSeek：`deepseek-v4-pro`
- Claude：`claude-sonnet-4-6`

用户可以直接改模型名和接口地址。API Key 默认只保留在当前页面内；勾选“记住 Key”后才会保存到浏览器 `localStorage`。后端不会把 Key 写入文件。

调用路径：

```text
浏览器 -> 本机 /api/model-analyze -> 对应模型服务商
```

没有 API Key、额度不足或网络失败时，页面会回退显示本地规则判断。
