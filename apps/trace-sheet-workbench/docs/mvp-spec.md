# Spec：迹算 TraceSheet MVP

## 目标

为需要反复整理业务表格的运营、财务和项目人员提供一个本地优先的 Excel 工作台。用户用自然语言描述目标，系统生成受限、可复核的操作计划；真正的数据变换由浏览器内的确定性引擎执行，并保留差异预览、版本链和审计记录。

## 与 AI HUB 的产品边界

- `/data/` 负责数据画像、图表和分析报告。
- `/tracesheet/` 负责多表合并、字段清洗、基础公式、差异预览、版本回滚和审计导出。
- 顶部导航、卡片、按钮、焦点状态和响应式断点使用 AI HUB 的共享视觉语言。
- 表格网格背景和绿色操作轨迹是迹算自己的视觉识别，不复制其他工具的业务布局。

## 技术栈

- Next.js + React + TypeScript：页面和同源 API route。
- SheetJS + Papa Parse：Excel、CSV 解析与 Excel 导出。
- Zod：模型计划与 API 输入校验。
- Vitest：确定性分析、操作计划和 Hub 接入测试。

## 模型与数据边界

- 只通过 AI HUB 项目级代理调用 `gpt-*` 型号，不接收独立 API Key。
- 只把任务描述、文件名、工作表名、列名和行数发送给模型，不发送完整单元格数据。
- 模型只生成 JSON 操作计划，不生成或执行 Python、SQL、Shell、JavaScript。
- 所有模型计划必须通过 Zod 和领域规则校验；模型不可用时切换到本地确定性计划器。
- 数据文件默认在浏览器内解析和处理，原始源版本不被覆盖。

## 支持的操作

- `JOIN`：按真实字段精确左连接或内连接。
- `UNION`：纵向追加结构兼容的数据源。
- `TRIM`：清理文本首尾空格。
- `NORMALIZE_DATE`：标准化日期格式。
- `REPLACE`：在指定字段中替换文本。
- `DEDUP`：按指定键去重，执行前必须确认高风险操作。
- `ADD_FORMULA_COLUMN`：生成只含字段引用、数字、括号和基础算术符号的公式列。

## 验收标准

- 可以同时导入多个 `.xlsx` 或 `.csv`，每个非空工作表成为独立数据源。
- 生成计划后可查看步骤、风险、变化行、新增字段、未匹配记录和结果抽样。
- 执行计划会创建不可变版本，可切回历史节点后继续形成新分支。
- 可以查看质量与异常、导出带公式的 Excel 和 Markdown 审计记录。
- `/tracesheet/` 桌面与手机布局无页面级横向溢出，支持键盘焦点和 reduced motion。
- Hub 模型不可用时仍可完成本地计划、清洗、预览和导出。

## 当前限制

- 暂不完整保留 `.xls`、VBA、复杂样式、图表和数据透视表。
- 版本记录使用浏览器轻量存储，尚不提供多人协作或服务端对象存储。
- 公式只支持基础算术表达式，高级 Excel 函数需要后续扩展受限 AST。
