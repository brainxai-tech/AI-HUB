# 迹算（TraceSheet）

用自然语言完成 Excel / CSV 合并、清洗、公式生成和异常解释，并为每一步保留差异预览、操作证据、不可变版本和回滚入口。

## 当前 MVP

- 同时上传多个 `.xlsx` / `.csv`；Excel 中的每个非空工作表会成为独立数据源。
- 自然语言生成受限操作计划；支持精确左连接、纵向追加、文本去空格、日期标准化、替换、去重和算术公式列。
- 模型只生成 JSON 计划，所有外部响应都经过 Zod 与领域规则校验；真正的数据变换在浏览器内由确定性引擎执行。
- 执行前显示结果行数、变化行、新增字段、未匹配警告和结果抽样。
- 高风险去重必须单独确认；原始数据不会被覆盖。
- 每一步产生不可变版本，可切回任意历史版本后创建新分支。
- 数据质量、异常方法、源字段/行号和确定性说明可单独复核。
- 导出带公式的 `.xlsx` 结果和 Markdown 审计记录。
- 项目状态保存在当前浏览器；超过轻量存储上限时仍可在当前会话使用并导出。

## AI HUB 模型接入

迹算不单独接收或保存 API Key。自然语言计划请求通过项目同源 `/api/plan` 进入 AI HUB 项目级代理，并使用 Hub 已启用的 GPT 型号；浏览器中没有供应商 Key 或项目令牌。

请求只发送用户任务和数据集元数据（文件名、工作表名、列名、行数），不会上传完整表格内容。Hub 未配置可用型号、上游超时或模型计划校验失败时，应用会自动切换到本地确定性计划器，文件清洗和导出仍可继续使用。

## 核心安全边界

- 不执行模型生成的 Python、SQL、Shell 或任意 JavaScript。
- 单元格内容只作为数据，不能覆盖系统计划规则。
- 公式只允许 `[列名]`、数字、括号与 `+ - * /`；导出时转成逐行 Excel 引用。
- 非公式字段以 `= + - @` 开头时会转义，降低 CSV/Excel 公式注入风险。
- 单文件 MVP 上限为 50 MB；原始源版本始终保留。

## 当前限制

- 暂不支持 `.xls`、VBA 宏、复杂样式、图表和数据透视表的完整保留。
- 本地自然语言计划器聚焦高频中文任务；复杂或含糊请求会优先使用 AI HUB 已配置的 GPT 型号。
- 版本数据当前使用浏览器轻量存储，团队协作、服务端对象存储和大文件异步执行属于下一阶段。
- MVP 公式只支持基础算术表达式；`SUMIFS`、`XLOOKUP` 等高级函数将在公式 AST 扩展后加入。
