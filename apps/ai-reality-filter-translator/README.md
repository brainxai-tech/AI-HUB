# AI · 现实滤镜翻译器

上传一张日常照片，把可见事实翻译成赛博都市、暖风手绘日常、侦探现场或末日避难所等世界观，输出短故事与图像生成提示词。

## 本地运行

```bash
npm install
npm run dev
```

默认地址：

```text
http://127.0.0.1:5186
```

## Hub 统一模型

- API Key 只在 AI Hub 配置一次，本项目不会显示、接收或保存 API Key。
- 所有真实模型请求都通过 Hub 项目级代理发送。
- 本项目只展示和接受 Hub 启用的 `gpt-*` 型号。
- 型号通过页面顶部统一模型选择器切换，项目内部不提供厂商或模型下拉框。
- 上传图片会先在浏览器中压缩，再作为当前项目的多模态请求发送给 Hub。

## 安全边界

- 结果用于虚构娱乐表达，不对真实人物作身份识别或犯罪判断。
- 使用通用视觉语言，不直接模仿具体在世艺术家。
- 自定义系统提示词不能覆盖输出结构、照片事实、所选世界观或安全规则。

## 验证

```bash
npm run verify
```
