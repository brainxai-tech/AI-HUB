# 吟舟 AI

可解释、可修改的古典诗词共创工作台。首版已经实现“触景—起稿—照律—炼字—明意—成笺”的本地 H5 主路径。

## 已实现

- 五言绝句、七言绝句、七言藏头三种体裁。
- 清雅、雄浑、自然三稿候选。
- AI HUB 统一 GPT 型号与项目级代理。
- 句数/字数、基础韵脚、重复字和藏头检查。
- 逐句编辑、候选替换、锁句、撤销和重做。
- 本地作品集，可载入后继续修改。
- 1080×1440 PNG 诗笺导出，带显式“AI 共创”标识。
- 桌面与手机响应式界面、可见键盘焦点和减少动态效果支持。

## 本地运行

```powershell
npm install
npm run dev
```

在 AI HUB 仓库根目录运行 `npm run start:suite` 后打开 <http://127.0.0.1:4194/poetry/>。单独运行本项目时默认地址为 <http://127.0.0.1:5228>。

## 验证

```powershell
npm run verify
```

## 模型模式

模型和凭证统一由 AI HUB 管理。页面不包含密钥或供应商地址输入框；项目服务通过 Hub 项目身份调用项目级 GPT 代理。用户可在统一工具栏中选择本项目可用的 GPT 型号。

## 数据与合规

- 作品集只保存在当前浏览器 localStorage，清理浏览器数据后无法恢复。
- 导出图片包含显式“吟舟 AI · 人机共创内容”标识。
- 输入含基础安全拦截；公开上线前仍需接入正式内容审核、用户协议、投诉机制、日志策略和隐式文件标识。

## 已知边界

- 诗律镜是 `basic-rhyme-v1` 基础校验，只覆盖句数、字数、简表韵脚、重复字与藏头；完整平仄和古音需接入权威、版本化韵书。
- 首版不含账号、支付、公开社区、云同步和真实照片视觉识别。
- Canvas 导出已含显式标识，但尚未写入 PNG 隐式元数据。

## 技术结构

- React + TypeScript + Vite
- Express 模块化单体与统一 API
- Vitest 领域/校验测试
- Canvas 原生诗笺导出
