# AI 数据分析师

本地优先的 CSV / Excel 数据分析工作台，提供确定性数据画像、异常检测、自动图表、洞察建议，并通过 AI Hub 生成中文分析报告。

## 功能

- 上传 `.csv` 或 `.xlsx` 文件并在浏览器内完成解析。
- 计算数据质量、缺失率、重复行、离群值、趋势和类别占比。
- 自动生成图表、确定性洞察与下一步建议。
- 仅把压缩后的结构化分析摘要发送给模型，不默认发送完整原始数据。
- 支持导出 Markdown 报告。

## Hub 统一模型

- API Key 只在 AI Hub 配置一次，本项目不会显示、接收或保存 API Key。
- 所有真实模型请求都通过 Hub 项目级代理发送。
- 本项目只展示和接受 Hub 启用的 `gpt-*` 型号。
- 型号通过页面顶部的统一模型选择器切换，项目内部不再提供厂商或模型下拉框。
- 数值结论来自本地确定性分析，不依赖模型生成。

## 本地运行与验证

从仓库根目录按统一启动说明运行，或在本目录执行：

```powershell
npm install
npm run dev
npm run verify
```
