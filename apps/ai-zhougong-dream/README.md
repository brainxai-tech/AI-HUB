# AI 周公解梦

输入梦境、醒来情绪和标签，先检索本地《周公解梦》RAG 语料，再通过 Hub 当前 GPT 型号生成结构化报告、本机历史和分享图。

## 功能

- 平衡、周公、心理三种解读风格。
- 传统意象、心理视角、现实启示、今日建议和娱乐免责声明。
- 本地 RAG 引用只由服务端检索器提供，模型不能虚构原文。
- 报告历史、用量统计、复制和分享图下载。

## 本地运行

```bash
npm install
npm run dev
```

默认地址：`http://127.0.0.1:5173`。

## Hub 统一模型

- API Key 只在 AI Hub 配置一次，本项目不会显示、接收或保存 API Key。
- 所有真实模型请求都通过 Hub 项目级代理发送。
- 本项目只展示和接受 Hub 启用的 `gpt-*` 型号。
- 型号通过页面顶部统一模型选择器切换，项目内部不提供厂商或模型下拉框。
- Hub 未为本项目配置 GPT 型号时，生成按钮保持禁用，不会返回伪造的 AI 结果。

## 验证

```bash
npm run verify
```

该命令会运行 Vitest、TypeScript 检查和生产构建。
