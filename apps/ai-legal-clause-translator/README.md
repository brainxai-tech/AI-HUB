# AI 法务条款翻译器

把复杂合同条款转换成大白话，并拆解用户义务、对方权利、风险、模糊措辞和建议追问。结果仅用于合同阅读辅助，不替代律师意见。

## Hub 统一模型

- API Key 只在 AI Hub 配置一次，本项目不会显示、接收或保存 API Key。
- 所有真实模型请求都通过 Hub 项目级代理发送，并携带项目级访问凭据。
- 本项目只展示和接受 Hub 启用的 `gpt-*` 型号。
- 型号通过页面顶部的统一模型选择器切换，项目内部不再提供厂商或模型下拉框。

## 本地运行与验证

从仓库根目录按统一启动说明运行，或在本目录执行：

```powershell
npm install
npm run dev
npm run verify
```
