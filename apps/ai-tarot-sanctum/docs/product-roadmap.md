# AI 塔罗圣殿未来开发计划

更新日期：2026-06-05

## 产品北极星

AI 塔罗圣殿不是百科式牌义工具，也不是聊天机器人。它的核心体验是“判断型三牌阅读”：

1. 先给明确倾向：能 / 不能
2. 说明置信度：强 / 中 / 弱
3. 解释为什么：根源、现状、趋势三张牌如何支持判断
4. 给出怎么做：下一步、避坑、7 天观察点

所有结论都必须表达为“本次牌阵倾向”，不承诺现实保证，不替代医疗、法律、金融或心理健康建议。

## 当前架构决策

更新日期：2026-07-01

当前产品已经从“用户自带兼容 API Key”调整为“本地牌阵 + AI Project Hub 统一模型网关报告生成”：

- 本地代码负责 78 张牌库、三张不重复抽牌、根源/现状/趋势牌位、正逆位、历史保存和复盘状态。
- Hub 模型网关负责塔罗文案解释器和判断报告生成器：明确回答、置信度、为什么、怎么做、支持/阻力信号、改判条件、综合解读和风险提示。
- 页面不再要求用户填写项目级 API Key；模型供应商、模型名和密钥统一由 AI Project Hub 模型设置维护。
- 生成报告时由本地 Next.js API route 向 Hub gateway 请求模型服务；浏览器 localStorage 只保存历史记录和复盘状态。
- 旧版浏览器 localStorage 中保存过的兼容 API 配置会在进入页面时自动清理。
- 本地规则解读引擎继续保留，用于测试、兼容旧历史和未来 fallback，不再被描述为当前主流程。

## V1 结论优先强化版

目标用户：想快速得到方向的人，例如“能不能复合”“这个机会能不能做”“这笔投入值不值得”。

核心价值：用户第一眼看到明确回答，不再先读长段综合分析。

验收标准：

- 结果页首屏必须出现“明确回答”。
- 每次新解读必须返回内部稳定 verdict：`supportive` 或 `blocked`。
- UI 将 verdict 翻译为“能 / 不能”。
- 旧历史缺 verdict 时显示“暂无结论”，不得默认显示“能”。
- “为什么”必须引用三张牌、三个位置和正逆位。
- “你该怎么做”至少 3 条，且每条可执行。
- 自动测试覆盖支持牌组、阻力牌组、score breakdown 和旧历史迁移。

本轮已执行：

- 结论模型改为稳定内部枚举。
- 增加 `scoreBreakdown`，记录每张牌的分数贡献。
- UI 增加旧历史安全 fallback。
- 历史解析支持旧版 `combined + actionAdvice` 记录迁移。

## V2 问题意图识别版

目标用户：不会写判断型问题，但希望得到直接回答的人。

核心价值：把自然问题转成可判断口径，减少“问得太泛导致回答含糊”。

计划任务：

- 增加本地 `QuestionIntent` 规则，不接入 API。
- 关系意图：推进、复合、边界、沟通、时机。
- 事业/财富意图：机会、金钱、执行、冲突、时机。
- 结果页显示“本次判断口径”。
- 推荐问题改成更适合能/不能判断的问题。

## V3 可信度与反证版

目标用户：不只想知道能不能，还想知道什么会让结论反转的人。

核心价值：给出支持信号、阻碍信号和反转条件。

计划任务：

- 展示支持结论的信号。
- 展示阻碍结论的信号。
- 展示“什么情况会改变判断”。
- 让置信度解释来自逆位数量、趋势位权重、大阿卡纳数量和主题牌组加权。

## V4 复盘与连续观察版

目标用户：围绕同一个问题多次观察变化的人。

核心价值：把单次占卜变成本地私密复盘记录。

计划任务：

- 历史记录支持主题筛选。
- 保存时可添加标签。
- 保存后可记录现实反馈：发生了、没发生、还不清楚、我的备注。
- 同一问题下展示最近多次结论变化。
- 复盘页提醒：先观察现实反馈，再重新抽牌。

## QA 验收矩阵

P0：

- 明确回答一定出现。
- 为什么足够具体。
- 怎么做可以执行。
- 历史兼容旧记录。
- 本地牌阵生成稳定；报告生成必须通过 AI Project Hub 模型网关。
- 不需要用户账号、远程数据库或云同步。
- 关系与事业/财富两条完整流程都可用。

P1：

- 空问题、坏 localStorage、重复保存、reduced motion 可用。
- 移动端 375px 无重叠。
- 历史日期异常不显示 `Invalid Date`。
- 旧记录缺 verdict 不误导用户。

P2：

- 增加 Playwright smoke。
- 增加移动端/桌面端视觉截图基准。
- 增加 no-external 扫描。

## 发布计划

本地 Windows 发布必须验证：

```powershell
npm run verify
$env:NO_OPEN="1"; cmd /c start-ai-tarot-sanctum.cmd
```

人工验收：

- 双击 `start-ai-tarot-sanctum.cmd` 打开本地网页。
- 完成一次关系解读。
- 完成一次事业/财富解读。
- 保存、刷新、回放历史。
- 清空历史。
- 关闭服务后再次双击启动。

当前项目不是 git 仓库。每次发布前应复制整个目录作为快照，或至少备份：

- `package.json`
- `package-lock.json`
- `start-ai-tarot-sanctum.cmd`
- `scripts/start-dev-server.mjs`
- `lib/`
- `components/`
- `app/`
