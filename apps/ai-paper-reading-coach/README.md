# AI · 论文阅读教练

一个工具优先的论文阅读工作区，帮助用户导入论文、检查章节、生成论文地图、解释选段、带引用回答问题并导出复习笔记。

## 功能

- 粘贴论文文本或上传带文本层的 PDF。
- 支持 arXiv、DOI 和 PDF 链接导入。
- 自动切分标题、摘要、引言、方法、结果、讨论和结论等章节。
- 生成论文地图、逐段解释、问答和复习包。
- 输出显式区分“基于论文文本”“推测”和“不确定”。

## 本地运行

```bash
npm install
npm run dev
```

默认地址：

```text
http://127.0.0.1:5186
```

## Hub 统一模型

- API Key 只在 AI Hub 配置一次，本项目不会显示、接收或保存 API Key。
- 所有真实模型请求都通过 Hub 项目级代理发送。
- 本项目只展示和接受 Hub 启用的 `gpt-*` 型号。
- 型号通过页面顶部的统一模型选择器切换，项目内部不再提供厂商或模型下拉框。

## 验证

```bash
npm run verify
```

该命令会运行类型检查、Vitest 和生产构建。
