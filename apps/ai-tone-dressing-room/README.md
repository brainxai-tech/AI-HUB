# AI · 语气化妆间

把原话调整为更坚定、更温柔、更高级、更像本人或更有边界感的表达，并展示语气变化解释与雷达图。

## 运行恢复产物

```bash
npm install
npm start
```

默认地址：`http://127.0.0.1:5197/tone/`。

## Hub 统一模型

- API Key 只在 AI Hub 配置一次，本项目不会显示、接收或保存 API Key。
- 所有真实模型请求都通过 Hub 项目级代理发送。
- 本项目只展示和接受 Hub 启用的 `gpt-*` 型号。
- 型号通过页面顶部统一模型选择器切换，项目内部不提供厂商或模型下拉框。

## 源码恢复说明

本目录仅保留服务器上找回的生产构建产物、包元数据与验证测试，不代表完整 TypeScript/React 源码已经恢复。详情见 `SOURCE-RECOVERY.md`。
