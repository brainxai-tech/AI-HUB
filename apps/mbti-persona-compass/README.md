# 人格罗盘 Persona

一款中文 16 型人格倾向测试 MVP。通过 32 道情境题测量 E/I、S/N、T/F、J/P 四个连续维度，生成可解释的类型画像和行动建议。

## 已实现

- 32 道原创情境题，四个维度各 8 题，正反方向平衡
- 5 档倾向量表与连续百分比计分
- 全部 16 型人格的优势、盲点、工作、关系与成长建议
- 进度本地自动保存、继续测试、重新测试
- 完成计分后自动调用 AI，基于 32 道具体选择生成理由、证据与矛盾信号解释
- AI 只能解释本地计分结果，不能重新判型；每个维度必须引用真实题号
- 原生分享与结果文字复制
- 桌面端、移动端响应式界面及无障碍焦点样式
- 计分逻辑和 16 型内容完整性自动测试

## 在 AI HUB 中运行

在 AI HUB 仓库根目录执行：

```powershell
npm install
npm run start:suite
```

打开 <http://127.0.0.1:4194/mbti/>。也可以在本目录运行 `npm run dev`，默认独立地址为 <http://127.0.0.1:5177>。

## AI 设置

模型和凭证统一由 AI HUB 管理。页面不接收、保存或转发用户密钥；项目服务通过 Hub 项目身份读取 GPT 型号并调用项目级代理。用户可在统一工具栏中选择本项目可用的 GPT 型号。

## 验证

```powershell
npm run verify
```

## 产品边界

本产品参考 MBTI 四维偏好模型，用于自我探索与娱乐，不构成专业心理评估或临床诊断。答题进度保存在当前浏览器；生成 AI 解读时，32 道答案、四维结果和基础画像会通过 AI HUB 项目级代理发送给当前所选 GPT 型号，不写入项目服务日志。

完整策划见 [docs/PRODUCT-PLAN.md](docs/PRODUCT-PLAN.md)。
