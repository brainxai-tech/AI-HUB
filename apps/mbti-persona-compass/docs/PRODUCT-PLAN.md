# 人格罗盘 Persona｜产品策划与 MVP 方案

版本：1.0
日期：2026-07-29
状态：已完成 MVP

## 1. 产品一句话

一份 5–7 分钟完成、结果可解释、建议能行动的中文 16 型人格倾向测试。

品牌名使用「人格罗盘 Persona」，公开传播时以“16 型人格倾向测试”描述产品，不把 MBTI 注册商标作为主品牌，也不暗示官方授权。

## 2. 用户与问题

### 核心用户

- 18–35 岁、对自我探索感兴趣的学生与职场人
- 想理解自己在工作、关系和决策中的稳定偏好
- 愿意把结果发给朋友，借此开启交流

### 现有痛点

1. 题目抽象或翻译腔重，用户不知道该按“理想的自己”还是“真实的自己”回答。
2. 结果只给四个字母与正面标签，缺少得分强度和原因解释。
3. 百分比接近 50% 时仍被强行归类，用户觉得“不像我”。
4. 报告好看但不可行动，看完即走，没有下一步。

### 核心机会

把人格类型从“身份标签”改造成“当前偏好的坐标”：说明四维强度，承认中间地带，并给出三个可在本周验证的小实验。

## 3. 产品定位

| 项目 | 定义 |
| --- | --- |
| 核心价值 | 快速看见自己的思维与行动偏好 |
| 差异点 | 情境化原创题、连续得分、低置信度解释、行动建议 |
| 使用场景 | 自我复盘、朋友交流、团队破冰、职业探索入口 |
| 产品语气 | 清醒、温和、不神化标签 |
| 视觉记忆 | 一枚会随进度和结果改变的四向人格罗盘 |

## 4. MVP 核心闭环

1. 用户在首屏理解测试用途、时长与隐私承诺。
2. 按最近六个月的真实状态回答 32 个情境题。
3. 系统在浏览器本地自动保存，每题后自动前进，可返回修改。
4. 完成后由本地规则生成四字母类型与四维百分比。
5. AI 在不改变类型的前提下，结合 32 道选择生成可追溯的理由与解释。
6. 用户查看题号证据、反向信号、工作关系画像，并选择一个成长小实验。
7. 用户复制或分享结果，形成自然传播。

## 5. 题库与计分模型

### 题库结构

- E/I 能量方向：8 题
- S/N 信息方式：8 题
- T/F 决策依据：8 题
- J/P 行动节奏：8 题
- 每个维度两个方向各 4 题，避免一边倒的表述偏差
- 使用工作、关系、学习、社交、计划等现实情境

### 作答量表

`完全不像我 (-2)`、`比较不像我 (-1)`、`看情况 (0)`、`比较像我 (+1)`、`非常像我 (+2)`。

每题声明一个维度和陈述方向。若陈述方向是该维度第一极，则答案值正向累加；若为第二极，则反向累加。最终把每维原始分线性映射到 0–100%，高于或等于 50% 选择第一极，否则选择第二极。

当维度离 50% 的距离小于 12.5 个百分点（置信度低于 25%）时，报告明确提示用户处于“弹性区间”，避免把中间倾向解释为测试失效。

### 解释边界

- 结果描述“偏好”，不描述能力高低。
- 不提供招聘筛选、疾病判断或伴侣匹配结论。
- 不声称科学诊断效力。
- 全中立答案会按确定性规则生成类型，但报告同时显示 50/50 和弹性提示；正式商业版应增加平局追问题。

## 6. 功能范围

### 本次已交付

- 开始、继续、退出和重新测试
- 32 题逐题体验与实时进度
- 本地持久化
- 四维计分与 16 型判定
- 16 份原创结果报告
- OpenAI 兼容 AI 解释层：逐维理由、题号证据、矛盾信号与行动实验
- BYOK 设置、安全服务端代理、会话级 Key 保存和失败重试
- 分享、复制、响应式布局
- 测试与构建脚本

### 本次不做

- 登录、云端历史、好友关系
- 付费报告与支付
- 团队后台与 HR 筛选
- 多语言、原生 App、公开排行榜

## 7. 信息架构

```text
开始页
├─ 开始新测试
└─ 继续未完成 / 查看上次结果
   ↓
答题页（32 题）
├─ 选择 5 档答案
├─ 上一题
└─ 保存退出
   ↓
结果页
├─ 类型与一句话画像
├─ 四维百分比
├─ 优势 / 工作 / 关系 / 盲点
├─ 三个成长实验
└─ 分享 / 复制 / 重测
```

## 8. 商业化建议

### 免费层

保留当前完整基础报告，承担获客与分享传播。

### 付费层（建议 9.9–19.9 元一次性）

- 细分到四维组合的 12–20 页深度报告
- 职业环境偏好、沟通冲突模式、压力状态画像
- 可下载的长图/PDF 和 30 天成长练习

### B 端延伸

只用于团队沟通与破冰，不用于招聘淘汰。按团队报告或工作坊收费，提供团队偏好分布、沟通提醒与会议方式建议。

## 9. 冷启动与增长

1. 先邀请 30–50 位真实用户完成，收集“最像/最不像”的具体段落。
2. 围绕“你的四个字母有多确定”制作结果卡，突出百分比和弹性区间。
3. 小红书/朋友圈内容不只发类型榜单，而发具体冲突场景，例如“同是 I，为什么有人爱开会”。
4. 分享落地页展示朋友结果摘要，再引导“测出你的坐标”。
5. 二期增加双人对照报告，形成邀请闭环。

## 10. 北极星指标与漏斗

北极星指标：每周完成测试并阅读至少两个结果模块的有效用户数。

建议埋点：

- `test_started`
- `question_answered`（只记题号与耗时，不记具体答案）
- `test_resumed`
- `test_completed`
- `result_section_viewed`
- `result_shared`
- `retest_started`

关键漏斗目标：

| 指标 | MVP 目标 |
| --- | --- |
| 首屏 → 开始 | ≥ 45% |
| 开始 → 完成 | ≥ 65% |
| 结果页 → 分享/复制 | ≥ 12% |
| 7 日内重测或回访 | ≥ 8% |

## 11. 路线图

### V1.1：校准（1–2 周）

- 对首批用户做题目理解度访谈
- 统计每题选择分布、完成时长和退出位置
- 调整区分度低或社会赞许偏差强的题目
- 对 50/50 平局增加 1–2 道动态追问题

### V1.2：传播（2–4 周）

- 生成可保存的结果长图
- 增加好友结果对照与沟通建议
- 增加匿名访问分析和渠道参数

### V2：付费验证（4–8 周）

- 深度报告样板与小额支付
- 压力态、工作态与亲密关系态子量表
- 团队破冰版试点

## 12. 风险与处理

| 风险 | 处理 |
| --- | --- |
| MBTI 商标与授权 | 不使用官方标识，不声称官方测试，主品牌为人格罗盘 |
| 用户把结果当诊断 | 首尾明确娱乐与自我探索边界 |
| 题库效度不足 | 上线前做小样本认知访谈和项目分析，不宣传专业效度 |
| 类型刻板化 | 展示连续百分比、弹性区间和可变化声明 |
| 隐私担忧 | 进度只存本地；AI 解读时仅把答题与结果发往用户配置的服务商，并明确告知 |
| AI 解释幻觉 | 服务端锁定本地类型；提示词禁止改判与编造；结构强制引用真实题号 |
| 第三方 API 数据处理 | 由 AI HUB 统一管理模型与凭证；界面和 README 明示答案会经 Hub 项目代理发送给所选 GPT 型号 |
| 分享同质化 | 结果卡突出个人强度组合，而非只显示四字母 |

## 13. MVP 验收标准

- 用户能在桌面和手机完成全部 32 题。
- 刷新或退出后能继续未完成进度。
- 返回上一题修改不会增加答题数量。
- 16 种明确偏好输入都能得到对应类型。
- 结果展示四维百分比，且每维合计为 100%。
- 16 型均有完整原创报告和三个行动建议。
- AI 解读必须保持本地判型，四个维度各引用 1–3 个真实题号。
- Hub 未配置、项目鉴权失败、限流和模型格式错误都有可恢复界面。
- 分享不支持时自动退化为复制文本。
- TypeScript 检查、计分测试与生产构建全部通过。
