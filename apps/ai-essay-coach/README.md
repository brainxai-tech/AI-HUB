# 八百字 AI

面向中文作文场景的 AI 写作教练 MVP。产品把写作拆成审题、真实素材、三套提纲、约 800 字初稿和五维讲评，不把“一键代写”作为核心体验。

## 已实现

- 初一至高三、记叙文/议论文/材料作文、400—1500 字设置；
- 审题、跑题提醒和三个素材追问；
- 稳妥型、个性型、提分型三套提纲；
- 目标字数 ±5% 的可编辑初稿；
- 审题、立意、结构、内容、语言五维讲评；
- 作品本地保存、恢复、复制和 Markdown 导出；
- AI HUB 统一 GPT 型号与项目级代理；
- 输入校验、考试场景限制和未成年人隐私提示。

## 本地运行

```powershell
npm install
npm run dev
```

在 AI HUB 仓库根目录运行 `npm run start:suite` 后打开：

```text
http://127.0.0.1:4194/essay/
```

单独运行本项目时默认打开 `http://127.0.0.1:5216`。

## 验证

```powershell
npm run verify
```

服务运行时可执行浏览器冒烟测试：

```powershell
npm run browser-smoke
```

## 模型配置

模型和凭证统一由 AI HUB 管理。页面不包含密钥或供应商地址输入框；项目服务通过 Hub 项目身份调用项目级 GPT 代理。用户可在统一工具栏中选择本项目可用的 GPT 型号。

## 产品边界

- 生成内容是练习初稿，用户需要核对事实并继续修改；
- 不承诺高分、查重结果或绕过 AI 检测；
- 明显处于实时考试中的请求会被限制；
- 作品默认只保存在本地浏览器，可由用户随时删除。
