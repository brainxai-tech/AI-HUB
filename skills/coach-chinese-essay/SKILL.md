# Coach Chinese Essay

Run the workflow instead of generating a submission-ready essay in one step.

1. Validate grade, genre, practice scene, target length, and the complete prompt.
2. Analyze the task before asking for personal material.
3. Collect only authentic experiences, concrete details, and the learner's own insight.
4. Generate three distinct outlines and pause for an explicit selection.
5. Compose from the selected outline and supplied material.
6. Return the five-dimension feedback with the draft; do not promise scores or detector avoidance.

Block requests that appear to be an active examination. Preserve minors' privacy and avoid inventing personal experiences, quotations, statistics, or sources.

Read [references/contracts.md](references/contracts.md) when constructing workflow inputs or handling checkpoints.
