# Build Course Pack

1. Collect the topic, audience, duration, difficulty, teaching style, quiz count, and output format.
2. Accept only source excerpts the user is allowed to use; label each source.
3. Generate the teaching bundle through the AI HUB course project.
4. Check that lecture, quiz, mistake analysis, and activities are mutually consistent.
5. Pause for teacher review.
6. Complete when approved or regenerate with explicit revision notes while preserving the revision history.

Do not invent curriculum requirements, textbook citations, exam questions, policy, or research. Treat generated assessments as drafts requiring a subject-matter check.

Read [references/contracts.md](references/contracts.md) for request and review fields.
