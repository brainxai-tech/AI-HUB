    规则

    怎么玩

    1. 1掷骰并沿路线移动
    2. 2购买、竞拍或支付租金
    3. 3凑齐街区并均匀建房
    4. 4保住现金并让三名 Agent 全部破产
    基础回合移动、买地、收租
    掷骰移动行动页点击掷骰，棋子会沿城市路线移动。掷出对子会获得额外行动；连续三次对子会被送往交通管制区。
    买地与竞拍无人街道、交通站和公用事业可以直接购买；不想买或现金不足时进入拍卖，起价 10，每次至少加价 1，可出价或放弃。
    收租要求落到别人未抵押地块时先进入收租要求；业主要在下一次掷骰前确认收租，也可以放弃本次租金。
    地产经营街区、建造、交易
    街区垄断买齐同一街区后，未建房地块租金翻倍，并解锁建房。建房和卖房都要保持同街区均匀，不能只把一块地堆满。
    交通站与公用事业交通站不能建房，租金按持有数量提高；公用事业不能建房，租金按本次骰点的 4 倍或 10 倍计算。
    建房与抵押标准局每块地最多 4 栋房，第 5 级为地标；短局 3 栋房后即可升级地标。银行只有 32 个房屋和 12 个地标。
    地契交易与通行证交易只要当前是你的回合，就可从资产页向任一在场 Agent 发起双边报价；双方可提供无建筑地产和现金，交通管制通行证也可在对应交易阶段出售。抵押地产接手方需支付转让手续费。
    风险与特殊规则管制、税务、债务
    交通管制正常停到管制区只是临时停靠；被卡牌或三次对子送入管制时，下回合可用通行证、缴费离开，或最多尝试三次掷对子离开。
    所得税落到所得税格时，选择缴纳固定 200 金币，或按总资产 10% 结算；其它税费格按格面金额付款。
    债务处理现金为负时先卖房、抵押或自动清算；无法偿还则破产。你破产时，全部地产归还银行并变为无主，建筑和抵押同时清除；Agent 破产时按债权关系结算。
    对局模式与胜利短局、破产、生存
    官方短局设置页可选择官方短局；新开局时每个席位各免费获得 3 张地契，并启用短局的 3 房升地标。
    胜利条件对局没有轮数上限。你破产时立即失败；三名 Agent 全部破产时立即获胜。其它情况下游戏必须继续。
